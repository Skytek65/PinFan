# PinFan Marketing Site (GitHub Pages)

Static landing page for **PinFan**, served from this `docs/` folder.

## Enable GitHub Pages

1. Open the repo on GitHub: [Skytek65/PinFan](https://github.com/Skytek65/PinFan)
2. Go to **Settings → Pages**
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**
4. Choose branch **`main`** and folder **`/docs`**
5. Save — the site will publish at `https://skytek65.github.io/PinFan/` (or your custom domain if configured)

No build step is required. Edit `index.html` / `styles.css` and push to `main`.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Single-page marketing site |
| `styles.css` | Neon arcade theme |
| `assets/` | Optional images / icons |
